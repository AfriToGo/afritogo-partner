# Brand assets

`afritogo-logo.svg` is the orange combined horizontal icon + wordmark previously
supplied for AfriToGo. `afritogo-icon.svg` is the supplied orange icon-only export.
Both are copied unchanged from the uploaded AfriToGo header/footer logo package.
All visible artwork uses AfriToGo orange #F84803. No new logo shapes or lettering
have been generated, and no font files are distributed.

No applicant uploads are saved into this folder. It is only for public site assets.
